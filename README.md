# node-red-contrib-yandex-commander

Управление Яндекс Станциями в Node-RED через WebSocket (локальное API).

> Форк [node-red-contrib-yandex-station-management](https://github.com/nicediverofficial/node-red-contrib-yandex-station-management), переписанный на TypeScript.

## Поддерживаемые устройства

- Яндекс Станция / Мини / Мини 2 / Лайт / Макс
- Яндекс Модуль / Модуль 2
- JBL Link Music / JBL Link Portable

## Установка

```
npm i node-red-contrib-yandex-commander
```

Или через Manage Palette в Node-RED.
