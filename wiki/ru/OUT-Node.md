# Нода OUT

Ставится в конце flow и используется для отправки сообщений на устройства. Допускается использование нескольких нод OUT для одного и того же устройства, при этом данные будут от них передаваться через одно соединение с устройством.

## Player command

Управление воспроизведением колонки. Нода ждет, что в payload строкой придет одна из следующих команд:

| Команда    | Описание               |
|------------|------------------------|
| play       | Воспроизведение        |
| stop       | Остановка              |
| next       | Следующий трек         |
| prev       | Предыдущий трек        |
| forward    | Вперед на 10 секунд    |
| backward   | Назад на 10 секунд     |
| volumeup   | Увеличить громкость    |
| volumedown | Уменьшить громкость    |

## Voice command

Отправка команды, вместо того, чтобы говорить ее колонке голосом: "Включи свет", "Включи музыку", "Включи мой плейлист", "Отключись через 15 минут" и так далее.

## TTS (Text to Speech)

Воспроизведение голосом отправленных фраз. Не имеет ограничения по символам.

Параметры для TTS могут задаваться как в настройках, так и некоторые из них могут быть переопределены входящим сообщением.

### Параметры

- **Text** — откуда и какой текст проговорить:
    - из входящего сообщения (`msg.payload` по-умолчанию)
    - строго заданную строку
    - переменную из flow или global context
    - JSON: выбрать сообщение случайным образом из массива вида `["один", "два", "три"]`
- **Voice** — выбор голоса для генерации. Переопределяется через `msg.voice`
- **Effect** — эффекты для генерации голоса. Переопределяется через `msg.effect`

### Опции

| Опция              | Описание                                                                                                     | Переопределение         |
|--------------------|--------------------------------------------------------------------------------------------------------------|-------------------------|
| Volume             | Произносит фразу заданной громкостью. После произнесения уровень вернется в изначальный                      | `msg.volume`            |
| Whisper            | Произносит фразу шептом                                                                                      | `msg.whisper`           |
| Prevent listening  | Колонка после воспроизведения не "слушает", что ей ответят                                                    | `msg.prevent_listening` |
| Pause while TTS    | Ставит плеер на паузу на время речи. Продолжит воспроизведение, только если что-то играло на момент команды   | `msg.pause_music`       |

Все опции комбинируемы между собой.

### Добавление голосу жизни и красок

#### Расставляйте ударения
При необходимости ударные гласные в словах следует отмечать знаком «+»:

    остр+ота
    м+ука

#### Разделяйте слова
Длинные слова можно разбить на слова покороче и проставить ударения для каждого:

    мн+ого пр+офильный
    с+еми пал+атинск

#### Меняйте написание слов
Некоторые слова можно писать так, как они слышатся:

    «ненастный» — нен+асный
    «пожалуйста» — пож+алуста

#### Добавляйте паузы
Синтаксис: `sil <[ количество_миллисекунд ]>`

    смелость sil <[500]> город+а берёт

Каждый отделенный пробелами пунктуационный знак обозначается паузой в 50-100 мс.

#### Добавляйте [звуки из библиотеки](https://yandex.ru/dev/dialogs/alice/doc/sounds-docpage/)

    <speaker audio="alice-sounds-game-win-1.opus"> У вас получилось!

## Homekit Formatted

Ловит вывод от Homekit от устройств SmartSpeaker (вкл/выкл) и Television (вкл/выкл + пульт) модуля [NRCHB](https://github.com/NRCHKB/node-red-contrib-homekit-bridged).

Встроена функция проверки `hap.context`, предотвращающая зацикливание. Стыкуется напрямую с Homekit нодой.

Опция **"Default command"** указывает, какую голосовую команду запустить, если нет текущего трека для старта воспроизведения, а играть что-то надо. Например, "Включи мою музыку" или "Включи детские песни".

## Stop listening

Принудительное прерывание "слушания" Алисы при любом входящем в ноду сообщении. Аналогично команде 16 из раздела [RAW-команды](RAW-Commands).

## Play Music

Включение контента из Яндекс.Музыки по ID без необходимости использовать RAW-режим. Соответствует RAW-командам 6–8 из раздела [RAW-команды](RAW-Commands).

### Параметры

- **Music ID** — идентификатор контента (например, `44731403` для трека, `44731403:1234556` для плейлиста, `detskoe` для радио). Переопределяется через `msg.id`.
- **Music type** — тип контента: `track`, `artist`, `album`, `playlist`, `radio`. Переопределяется через `msg.type`.

На колонку уходит payload:

```json
{ "command": "playMusic", "id": "<id>", "type": "<type>" }
```

## RAW Command

Получает сообщение в формате JSON внутри payload и передает его колонке без обработки. Возможна отправка нескольких сообщений в одном payload в виде массива.

Полный перечень команд — в разделе [RAW-команды](RAW-Commands).
